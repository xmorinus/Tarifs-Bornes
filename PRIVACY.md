# Politique de confidentialité — BornePrix

Dernière mise à jour : [2026/10/10]

**Éditeur** : [Morin], [blois], [xm.morin@gmail.com]

## Ce que fait l'application
BornePrix affiche les bornes de recharge pour véhicules électriques autour de vous ou le long d'un trajet.

## Données utilisées
- **Position** : si vous la fournissez, elle sert à chercher les bornes proches. Elle reste sur votre téléphone ; aucun compte n'existe et nous ne la stockons pas sur un serveur.
- **Zone de recherche et destination** : pour obtenir les bornes et l'itinéraire, les coordonnées de la zone (et le texte de la destination) sont envoyés à des services publics : data.gouv.fr / transport.data.gouv.fr (bornes, disponibilité) et la Géoplateforme de l'IGN (adresses, itinéraire). Ces services peuvent journaliser votre adresse IP selon leurs propres règles.
- **Tarifs** : l'application télécharge un fichier de tarifs public hébergé sur GitHub ; GitHub peut journaliser votre adresse IP.
- **Réglages** (filtres, véhicule, dernière recherche) : enregistrés uniquement sur votre téléphone.

## Ce que nous ne faisons pas
Pas de compte, pas de publicité ni de traceur, pas de vente ni de partage de données, pas de paiement.

## Vos droits
Vous pouvez effacer toutes les données locales en désinstallant l'application ou via Réglages Android → Applications → BornePrix → Stockage → Effacer les données. Contact : [xm.morin@gmail.com].
